WORDLE: NO MERCY

How to play

Guess the five-letter word in six tries. Each puzzle has a different challenge.

Game 1 — Black Letter

One secret letter has been selected. You will not be told which letter it is. If you use it in a guess, you lose one available guess.

W Green means the letter is correct and in the correct position.
O Yellow means the letter is in the word but in the wrong position.
R Gray means the letter is not in the answer.

The black letter remains completely secret.

Game 2 — Time Challenge

Solve the word before the timer runs out. The normal Wordle rules apply.

Game 3 — Colourblind

Green and gray letters work normally, but yellow letters are shown as normal gray tiles.

W Green letters remain visible.
O Yellow letters appear as normal gray tiles, so you cannot tell that they are in the word.
