WORDLE: NO MERCY

How to play

Guess the five-letter word in as few tries as possible. But each game has a different challenge.

Game 1 — Time Challenge

Find the word before the timer runs out. The faster you solve it, the better.

W W is in the word and in the correct spot.
O O is in the word but in the wrong spot.
R R is not in the word.

Game 2 — Colourblind

Yellow letters are hidden. Green and gray letters work normally.

W Green letters remain visible because they are in the correct position.
R Gray letters remain visible because they are not in the word.

If a letter would normally be yellow, it simply appears as a normal gray tile.

Game 3 — Black Letter

One secret letter is selected for the puzzle. The letter is never revealed on screen.

W Normal Wordle rules still apply.
R Normal gray letters work as usual.
X The black letter is secret. If you enter it, you lose one available guess.

You will not be told which letter is black. You have to figure it out yourself.
